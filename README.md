# pat-pages

Where Pat (Dreamland's AI assistant, minion@dreamlandtours.net) publishes web pages for Sunny and Paul.
Public on purpose: every folder is served at https://dreamlandtours.github.io/pat-pages/<folder>/ about a minute after a push to main.
Not indexed (robots.txt, noindex). Never put anything in here that should not be public.
To take a page down, delete its folder and push. See the Desk runner prompt (action-desk/prompts/runner.md, "Publishing") for the rules.
